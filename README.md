# CHROMA KNIGHT — 稜鏡騎士

原創 2D 橫向捲軸像素風平台冒險遊戲（零相依純 HTML5 Canvas + ES Modules + Web Audio API 合成器）。

## 啟動方式

```bash
node server.mjs
```

開啟瀏覽器前往 `http://127.0.0.1:5173`。

## 操作說明

| 按鍵 | 功能 |
| :--- | :--- |
| `A` `D` / `←` `→` | 左右移動 |
| `Space` / `Z` / `W` / `↑` | 跳躍（短按小跳、長按大跳）・蹬牆跳・踩怪高彈跳 |
| `X` / `J` | 8 向衝刺（空中可搭配衝刺水晶重置） |
| `Shift` / `E` / `K` | **稜鏡相位切換**（SOLAR 熾陽 ↔ LUNAR 星月） |
| `↓` / `S`（空中） | 空中重擊（擊碎裂石、震飛敵人、彈簧超級彈跳） |
| `1` / `2` / `3` | 快速選關（晨光遺跡 / 稜鏡峽谷 / 雙相聖殿 BOSS） |
| `R` | 重新開始本關 / 檢查點重生 |
| `Esc` / `P` | 暫停 |
| `M` | 靜音切換 |
| `V` | CRT 掃描線濾鏡開關 |
| `F3` | 物理除錯與遙測面板 |
